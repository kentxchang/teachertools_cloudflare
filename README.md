# 教師課堂管理整合工具 — Cloudflare 版（cloudflareV1）

這一版**不再使用 Google Apps Script（GAS）與 Google 試算表**。網站和資料庫都放在 **Cloudflare 免費方案**上：

- **網站**：Cloudflare Workers（靜態網頁）
- **資料庫**：Cloudflare Durable Objects 內建的 SQLite 資料庫（部署時自動建立，不用手動建立資料庫或資料表）
- **檢視／編輯模式**：本工具以老師本人使用為主，可在不同電腦開啟。
  - **檢視模式**（預設，不用密碼）：只能查看目前的資料，加扣分、作業、出缺席、分組、座位表、兌獎、匯入、重置等修改操作都會被擋下，防止學生亂按。
  - **編輯模式**（輸入管理密碼）：可以修改資料，修改內容自動上傳雲端。
  - 第一次輸入的密碼會成為管理密碼；後端也會檢查密碼，沒有密碼的人即使繞過網頁也無法寫入資料庫。

主畫面的標題旁會顯示 `cloudflareV1` 版號。

## 二、與 GAS 版相比的優化（減少讀取與寫入）

| 項目 | GAS 版 | Cloudflare 版 |
|---|---|---|
| 自動上傳 | 每 10 秒把**全部資料**整包上傳 | 只上傳**有變動的那幾筆**，且連續操作時每 5 秒最多合併上傳一次 |
| 值沒變的存檔 | 也會觸發上傳 | 值相同就不上傳 |
| 「上次儲存時間」 | 寫入後又被當成新變動，造成**每 10 秒無限重複上傳** | 改存為本機狀態，不再觸發上傳 |
| 開啟網頁載入 | 每次下載**全部資料** | 只下載「上次同步之後」其他裝置改過的資料（第一次才下載全部） |
| 關閉網頁前沒上傳完 | 資料遺失 | 未上傳的項目會記在本機，切換分頁／關閉時立即送出，下次開啟也會自動補傳 |
| 後端 | 每次存檔逐列讀寫試算表 | 一次交易批次寫入 SQLite，並有索引，只讀取需要的列 |

資料平常仍存在瀏覽器（所以畫面操作不用等網路），雲端資料庫負責備份與跨裝置同步。

## 三、事前準備（只需做一次）

### 1. 註冊 Cloudflare 帳號

1. 打開 <https://dash.cloudflare.com/sign-up>
2. 輸入 Email 和密碼註冊，並到信箱點驗證信。
3. **不需要綁定信用卡**，免費方案就能使用本程式的所有功能。

### 2. 安裝 Node.js

部署工具 Wrangler 需要 Node.js。

1. 打開 <https://nodejs.org/>
2. 下載 **LTS（長期支援版）**，一路按「下一步」安裝完成。
3. 確認安裝成功：按 `Win` 鍵，輸入 `cmd` 打開「命令提示字元」，輸入：

   ```
   node -v
   ```

   出現像 `v22.x.x` 的版本號就代表成功。

## 四、部署到 Cloudflare（用指令，最推薦）

### 步驟 1：（可選）修改網址名稱

用記事本打開 `wrangler.jsonc`，第 3 行：

```
"name": "class-tools",
```

`class-tools` 會成為網址的一部分，可改成你喜歡的名字（只能用**英文小寫、數字和 `-`**），例如 `ming-class-tools`。

### 步驟 2：在本資料夾打開命令視窗

1. 用檔案總管打開本資料夾（看得到 `wrangler.jsonc` 那一層）。
2. 點一下上方的**網址列**，把內容改成 `cmd` 後按 Enter，就會在這個資料夾開啟命令提示字元。

### 步驟 3：登入 Cloudflare

輸入：

```
npx wrangler login
```

- 第一次執行會問 `Need to install the following packages ... Ok to proceed? (y)`，輸入 `y` 按 Enter。
- 瀏覽器會自動打開 Cloudflare 授權頁面，按 **Allow（允許）**。
- 看到 `Successfully logged in` 就完成了，可以關掉該網頁。

### 步驟 4：部署

輸入：

```
npx wrangler deploy
```

- 如果是第一次使用 Cloudflare Workers，會請你設定一個 **workers.dev 子網域**（例如輸入 `mrchang`），這會成為網址的一部分，請取一個好記的英文名稱。
- 完成後會顯示網址，例如：

  ```
  https://class-tools.mrchang.workers.dev
  ```

**這就是你的網站網址！**

> 💡 剛部署好的新網址，前幾分鐘（偶爾到幾小時）可能出現 `ERR_SSL_VERSION_OR_CIPHER_MISMATCH`，這是 Cloudflare 正在核發 HTTPS 憑證，**不是程式問題**，稍等一下再開即可。

### 步驟 5：資料庫設定？——已經自動完成了！

`wrangler.jsonc` 已經寫好資料庫設定，`npx wrangler deploy` 時 Cloudflare 會**自動建立**資料庫，不需要另外到後台建立資料庫、建資料表或貼任何設定。

想確認的話：

1. 登入 <https://dash.cloudflare.com/>
2. 左側選單點 **Workers & Pages**（「運算」底下）
3. 點進 `class-tools`，在「繫結 / Bindings」區域會看到名為 `CLASSDB` 的 **Durable Object**，這就是資料庫。
4. 左側選單 **Durable Objects** 頁面可看到 `ClassDB` 的使用量（請求數、儲存空間）。

資料庫裡只有兩張表：

| 資料表 | 內容 |
|---|---|
| `kv` | 所有資料（班級名單、學生、加扣分、作業、分組、座位表…），每個項目一列，並記錄版本號 |
| `meta` | 管理密碼（只存加密後的雜湊值，不存明碼） |

### 步驟 6：設定管理密碼並開始使用

> ⚠️ **部署完請馬上做這一步**：還沒設定密碼前，第一個輸入密碼的人就會成為管理者。

1. 打開網址，主畫面切到「🏫 班級與編輯模式」分頁。
2. 「🔐 編輯模式」區會提示「尚未設定管理密碼」。輸入一組密碼，按「🔓 進入編輯模式」。**這組密碼就是這個網站的管理密碼，請務必記住。**
3. 看到「已進入編輯模式」就完成了，之後的修改都會自動存到雲端。

## 五、檢視模式與編輯模式

| | 檢視模式 🔒 | 編輯模式 ✏️ |
|---|---|---|
| 怎麼進入 | 打開網址就是（預設） | 輸入管理密碼 |
| 查看班級、分數、作業、出缺席、座位表、統計圖 | ✅ | ✅ |
| 抽籤、計時器、下載報表 | ✅（抽籤結果不會存檔） | ✅ |
| 加扣分、作業登記與檢核、出缺席、分組、座位表調整、兌獎、新增／刪除班級、匯入、重置 | ❌ 會跳出密碼視窗 | ✅ |

- **進入編輯模式**：點畫面右下角的浮動按鈕「🔒」（或主畫面「🏫 班級與編輯模式」分頁的密碼欄），輸入密碼。
- **離開編輯模式**：點右下角的浮動按鈕「✏️」並確認鎖定。離開前會先把尚未上傳的資料傳完。
- **記住密碼**：輸入密碼時可勾選「在這台電腦記住密碼」，下次開啟自動進入編輯模式。**教室公用電腦請不要勾選**；沒勾選時，關閉瀏覽器後就會回到檢視模式。
- 下課離開教室電腦前，記得按「離開編輯模式」。

## 六、從舊的 GAS 版搬資料過來（只需做一次）

1. 確認舊版 GAS 的部署權限仍是「**任何人（Anyone）**」，並準備好舊版的 **GAS Web App 網址**（`https://script.google.com/macros/s/.../exec`）。
2. 打開**新的 Cloudflare 版**網站，先完成第四節步驟 6（設定管理密碼並進入編輯模式）。
3. 在主畫面「🏫 班級與編輯模式」分頁點「⚙️ 更多雲端設定」打開設定視窗 → 「3. 從舊版（GAS 試算表）搬移資料」→ 貼上舊網址 → 按「📦 匯入舊版資料」→ 確定。
4. 出現「已匯入 N 筆資料」後網頁會自動重新整理，所有班級資料就搬過來了。

> 也可以改用舊版的「📤 匯出資料」下載檔案，再到新版用「📥 匯入資料」逐班匯入。

## 七、在不同電腦使用

1. 在任一台電腦打開設定視窗 → 「4. 分享網址」→「🔗 產生網址 & QR Code」，取得網址（就是網站網址，**不含密碼**）。
2. 在其他電腦打開網址，預設為檢視模式；要修改資料時再輸入管理密碼。

> 同步方式：編輯模式下的修改約 5 秒內上傳；其他電腦在**下次開啟（或重新整理）網頁時**載入最新資料。請避免同時在兩台電腦修改同一個班級的同一項資料。
>
> 🔐 隱私提醒：知道網址的人都能以檢視模式看到班級資料（學生姓名、分數等），網址請勿公開張貼。

## 八、另一種部署方式：透過 GitHub（不想打指令的話）

1. 到 <https://github.com/> 註冊帳號，按右上角 **＋ → New repository** 建立一個新儲存庫（建議設為 **Private**）。
2. 在儲存庫頁面點 **uploading an existing file**，把 `public` 資料夾、`src` 資料夾、`wrangler.jsonc` 拖曳上傳（舊的 `index.html`、`homeworkPdf.html` 不用上傳），按 **Commit changes**。
3. 到 Cloudflare 後台 → **Workers & Pages** → **建立應用程式（Create application）** → 選 **匯入存放庫（Import a repository）** → 連結 GitHub 帳號並選擇剛剛的儲存庫。
4. 部署設定保持預設（部署指令為 `npx wrangler deploy`），按 **部署（Deploy）**。
5. 完成後，在該 Worker 的頁面可以看到網址。之後只要在 GitHub 上更新檔案，Cloudflare 會自動重新部署。

## 十、之後修改程式要怎麼更新？

修改 `public/` 裡的檔案（例如 `public/js/` 裡某個功能模組）或 `src/worker.js` 後，在本資料夾的命令視窗再執行一次：


## 十二、常見問題

**Q：忘記管理密碼怎麼辦？**
密碼只以加密雜湊保存，無法查回。若有電腦勾選過「記住密碼」，那台電腦仍可正常編輯，可先用「📤 匯出資料」備份。接著在 `wrangler.jsonc` 改一個新的 `name` 重新部署，產生一個全新的空白網站，設定新密碼後再用「📥 匯入資料」匯入。

**Q：按加扣分或其他按鈕時跳出密碼視窗？**
代表目前是檢視模式，輸入管理密碼即可修改。若顯示「管理密碼錯誤」，代表密碼與第一次設定的不同。

**Q：畫面顯示「❌ 雲端未連結」？**
通常是網路中斷或網站尚未部署完成，重新整理網頁即可。

**Q：右下角顯示「❌ 自動儲存失敗」？**
通常是網路中斷。資料仍保存在本機，網路恢復後會自動補傳；也可以按右下角的浮動按鈕「☁️」手動上傳。

**Q：瀏覽器的資料被清除了怎麼辦？**
重新打開網址，就會從雲端資料庫下載全部資料。

**Q：舊的「GAS 後端部署教學」和 Code.gs 去哪了？**
Cloudflare 版不再需要 GAS，已全部移除。
